# Instituto Aveloz

Landing page institucional desenvolvida para o Instituto Aveloz, com foco em desenvolvimento territorial sustentável, inclusão social e fortalecimento comunitário.

## ✨ Tecnologias Utilizadas

- React
- Vite
- Tailwind CSS
- JavaScript
- Lucide React

## 🎨 Características do Projeto

- Interface moderna e responsiva
- Design premium com foco institucional
- Componentização escalável
- Animações suaves
- Gradientes e efeitos visuais
- Estrutura otimizada para performance
- Layout adaptável para mobile, tablet e desktop

## 📁 Estrutura de Componentes

- Hero Section
- Sobre
- Áreas de Atuação
- Objetivos
- Governança
- Contato
- Footer

## 🚀 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/instituto-aveloz.git
````

Entre na pasta:

```bash
cd instituto-aveloz
````

Instale as dependências:

```bash
npm install
````

Execute o projeto:

```bash
npm run dev
````
